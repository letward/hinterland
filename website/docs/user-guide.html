1. Get started

Streamlined 1-click installation

  1. Download the official Windows installer from the download page.
  2. Launch Hinterland-Setup.exe — setup completes in seconds in your user account without requiring administrator rights or UAC prompts.
  3. Hinterland opens immediately, adds Start menu and desktop shortcuts, and registers as an available Windows web browser.

Only download Hinterland from the official website or its official release page. Because Hinterland installs cleanly to your user profile, you do not need administrative credentials on your Windows machine.

First run & Default Browser

On your first launch, a welcome card greets you on the New Tab page. You can set Hinterland as your default Windows web browser with 1 click, explore this User Guide, or dismiss the card and jump straight into browsing. You can also set Hinterland as your default browser anytime in Settings → General.

Your first window

Use the address bar to enter a website or search phrase. Open a new tab with the + button or Ctrl + L to focus the address bar. Close the current tab with Ctrl + W. Shortcuts can be changed in Settings.

2. Browse comfortably

Tabs and pinned tabs

Each tab keeps a page open without replacing the others. Pin a frequently used tab from its tab menu; pinned tabs take less space and remain available when you reopen the browser. Drag tabs to reorder them or use the tab menu to move them into a group. To ensure critical web apps, dashboards, or local development servers remain active, use Never sleep this site from the tab context menu or Command Palette to exempt them from automatic Memory Saver sleeping.

Tab Sound & Audio Management (Global Media Hub)

Tabs playing sound feature an animated speaker icon in the tab strip. Click the speaker icon to mute or unmute the tab instantly, use Ctrl + M, or right-click any tab to mute other tabs. The centralized Media Controller (Ctrl + Alt + M) displays live audio visualizers, playing tab counters, quick Play/Pause and Picture-in-Picture triggers, a Jump to playing / Jump to Playing Tab switcher (also in the tabstrip menu and Command Palette), and 1-click Mute All Tabs and Unmute All Tabs header actions.

Find in Page Power Search

Press Ctrl + F to open the Find bar. Hinterland supports precision in-page searching with dedicated toggle controls for Match Case (Alt + C) and Match Whole Word (Alt + W). Cycle through results with Enter (next) or Shift + Enter (previous).

Private tabs

A private tab is useful when you do not want local browsing history for that session. Private browsing does not make you anonymous to websites, your network, or your internet provider. Close private tabs when finished.

Reader mode and media

When a page supports it, Reader Mode removes distractions and presents the main article in a simpler layout. The media controls let you pause or resume supported audio and video without searching through tabs. Picture-in-picture keeps supported video visible while you work in another tab.

Search quickly & Custom Engines

Enter a search phrase in the address bar. You can choose your preferred search provider in Settings or switch it on the fly in the Command Palette. Keyword shortcuts (e.g. @ddg, @g, @gh, @yt, @w) route your query directly to your favorite engine. You can also export your custom search engine configurations to JSON, copy your search engines table via Copy Search Engines as Markdown, or import existing ones from file via the Command Palette.

3. Privacy and permissions

Protection by default

Hinterland includes tracker blocking, HTTPS-First navigation, Do Not Track, and referrer controls. Some pages may look different or fail to load when a site depends on third-party content. If a trusted page breaks, use its site controls rather than disabling protections everywhere.

Site Permissions & Shields Dashboard

Access the centralized Site Permissions & Shields manager from the Main Menu, Command Palette, or Settings. Here you can inspect all per-site hardware and location grants (camera, microphone, geolocation, notifications) with a live rule count badge, revoke permissions individually or per site, manage Site Shield protection exceptions with 1-click reset options, and copy a full Markdown audit via Copy Summary.

Cookies and saved data

Deleting site data can sign you out and remove preferences for that site. Before clearing data, make sure you know how you will sign in again. Do not save sensitive information on a shared computer. You can also inspect stored cookies per site with a live cookie count badge, copy them to your clipboard with Copy JSON, or export them as JSON from the Cookie Inspector.

Important: Privacy features reduce tracking in the browser, but they cannot protect information you deliberately submit to a website. Check the address and the site’s identity before entering passwords, payment details, or personal information.

5. Settings and extensions

Customize safely

Open Settings to change appearance, startup behavior, search, privacy defaults, shortcuts, downloads, and site permissions. If a setting has a per-site exception, that exception takes priority for the selected site. In the Shortcuts panel, search shortcuts with a live count badge and export a Markdown reference via Copy Cheatsheet.

Extensions

Install extensions only from sources you trust. Review the permissions shown before enabling one. Search installed extensions in the Extensions panel with a live active/total summary badge, copy your installed list via Copy Extensions List or structured JSON via Copy JSON, and disable or remove extensions you no longer use. An extension may be able to read or change pages depending on the access it requests.

Passwords

The password manager stores credentials in an encrypted vault protected by a password you choose. Use a strong, unique vault password and keep a safe recovery plan. If you forget it, encrypted data may not be recoverable. Never share your vault password, recovery material, or unlocked device.

Sync

If sync is available in your version, enable it only on devices you control. Use a strong account password and sign out on shared devices. Hinterland Cloud Sync supports zero-knowledge end-to-end encrypted synchronization of bookmarks, search history, reading list, quick notes, and browser preferences. You can configure granular sync toggles in Account Settings or turn sync off anytime.

6. Troubleshooting

A page will not load

  • Check the address and your connection.
  • Reload the page and try a new tab.
  • Review the site-permissions panel and privacy controls.
  • Temporarily test in a private tab to identify whether local site data is involved.

Hinterland feels slow

Open the Task Manager (Shift + Esc) to inspect processes, sort by Memory or CPU usage, put inactive tabs to sleep with 1 click, wake all sleeping tabs at once with Wake sleeping tabs, or copy a full Markdown process snapshot with Copy Report. Close unused tabs, pause heavy media, and disable extensions you do not need. Restart the browser after large sessions. Keep the application up to date using the official download page.

Something looks wrong

Open About Hinterland and click Copy Diagnostics (or use the Command Palette) to copy a privacy-safe summary of your browser, runtime, and session status. Record what you expected, what happened, the page address without private query details, and the steps that reproduce it. Do not include passwords, tokens, private notes, or personal browsing history. Send a concise report through the feedback form or the official issue page.

Resetting your setup

Before resetting browser data, export or write down anything you intentionally want to keep. Resetting can remove tabs, saved items, permissions, preferences, or vault data depending on the option selected. When uncertain, ask for help before confirming.

Safety rule: Support will never need your password, vault password, one-time code, or private browsing history. Keep those details private.

7. Accessibility and responsible use

Use system scaling, browser zoom, keyboard shortcuts, and reduced-motion preferences to make browsing comfortable. Keep focus visible and use headings and controls in their normal order. Hinterland is intended for lawful, respectful browsing; follow each website’s rules and protect other people’s information.

For release notes and downloads, visit the official website. For feedback, use the link in the site footer.
