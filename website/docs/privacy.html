Hinterland Browser

Privacy Policy

Effective date: November 23, 2026 · Last updated: November 23, 2026

Core Principle: Hinterland is a local-first, open-source web browser (MIT License). Your browsing history, bookmarks, reading list, quick notes, and passwords belong exclusively to you. Hinterland does not sell data, serve tracking ads, or build behavioral advertising profiles.

1. Data Stored Locally on Your Device

By default, Hinterland stores all browser data exclusively on your local machine in your user profile directory:

  • Browsing History, Bookmarks, Reading List & Quick Notes: Saved locally so the browser works offline and instantaneously.
  • Passwords (Hinterland Pass Vault): Encrypted locally using zero-knowledge AES-256-GCM encryption derived from your master password. Nobody outside your device can decrypt your vault.
  • Site Permissions & Shields: Camera, microphone, geolocation, notification, and tracker-blocking preferences are stored locally per site.
  • Private Tabs: Opened inside an isolated incognito session that does not write local browsing history after the tab is closed.

2. Optional Account & Zero-Knowledge Cloud Sync

Creating a Hinterland account is completely optional. If you choose to sign in and enable Cloud Sync in Settings → Account:

  • You control individually which categories are synchronized (bookmarks, search history, reading list, quick notes, and portable browser preferences).
  • You may set a client-side sync passphrase so your data is end-to-end encrypted before leaving your device.
  • Sync endpoints are hosted via Vercel and Supabase strictly to deliver your explicitly requested multi-device synchronization.

3. Network Requests & Updates

  • Web Browsing: Websites you visit receive standard HTTP/HTTPS requests from Chromium; Hinterland strips common tracking query parameters (such as utm_*, fbclid, gclid) and blocks known trackers when Shield protection is enabled.
  • Microsoft Store Package: Application updates are delivered exclusively through Windows / Microsoft Store; third-party auto-update checks are disabled inside Store builds.
  • Standalone Desktop Installer: Checks GitHub Releases (letward/Hinterland) solely to notify you of verified browser updates.
  • Optional Feedback Form: If you voluntarily submit feedback on the website, only the text and optional contact email you enter are submitted to create a GitHub issue.

4. Permissions Explained

Hinterland only requests operating-system permissions you explicitly approve when visiting websites (for example camera, microphone, geolocation, or notifications) and per-user protocol registration (hinterland://, plus optional http/https on standalone installers when chosen as default browser). No admin elevation is required.

5. Security & Contact

Hinterland isolates extensions under strict Manifest V3 sandboxing (`EXTENSION_PRELOAD`) and strict Content Security Policy enforcement. Source code and security documentation are publicly auditable at github.com/letward/Hinterland.

Questions, data deletion requests, or vulnerability reports can be submitted via GitHub Issues or GitHub Private Vulnerability Reporting (Security Advisories).
